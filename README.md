# PORT-SCANNER
### A Simple TCP Port Scanner Made in Python

## ⚠️ DISCLAIMER
This tool is made for EDUCATIONAL PURPOSE ONLY.
Don't use it on any system you don't own or have permission.
I am not responsible for any misuse.

## 📌 FEATURES
- Scan ports 1-1000
- Fast scanning with 0.3s timeout
- Cool Banner with figlet
- Shows Scan Start/End Time

## 🛠️ REQUIREMENTS
- Python 3.6+
- pyfiglet
- Internet

## 💻 INSTALLATION - TERMUX
```bash

pkg update && pkg upgrade
pkg install python
pip install pyfiglet
git clone https://github.com/tashfiqonbir/PORT-SCANNER
cd PORT-SCANNER

```
## Usage 
```bash
python portscanner.py
